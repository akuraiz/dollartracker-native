# v4 Alpha Test Checklist

## Data safety

- Add records in at least two profiles.
- Edit USD and KHR records.
- Confirm totals remain profile-specific.
- Export, clear test data, and restore a backup.
- Import a legacy backup into the selected profile only.

## Form and keyboard

- Amount field is one continuous glass surface in every dark theme.
- Focus Amount, Description, Date, and Note on iPhone.
- Save remains fully above the keyboard and accessory bar.
- Bottom navigation does not overlap the keyboard.
- Closing the keyboard restores navigation.

## Performance

- Add and History remain smooth with at least 150 records.
- No continuous background animation runs in iPhone thermal mode.
